# .github

Arquivos padrão da organização **useclineo**:

- `profile/README.md` — texto da página pública da organização.
- `.github/ISSUE_TEMPLATE/` e `.github/pull_request_template.md` — templates usados por qualquer repositório da organização que não tenha os seus próprios.

O repositório `clineo` tem templates próprios, que prevalecem sobre estes.
